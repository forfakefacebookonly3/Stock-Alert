### แก้จากข้อสรุประหว่างคุย
- **ทิศของระดับ Fibo:** ข้อสรุปเดิมเขียนว่า "0% อยู่ที่จุดเริ่มลาก ตามแบบ TradingView" ซึ่งไม่ตรงกับ TradingView — ใน TradingView จุดเริ่มคือ 100% (1) และจุดจบคือ 0% ระดับ retracement วัดย้อนกลับจากจุดจบ spec นี้ใช้แบบ TradingView: **จุดเริ่มลาก = 100%, จุดจบ = 0%**
- **ตำแหน่งป้ายระดับ:** ย้ายจากปลายขวาไปปลายซ้ายเหนือเส้น เพราะปลายขวาทับแท่งเทียนที่อยู่หลังช่วง

## Schema เพิ่มใน `alerts.json`

```json
{
  "symbol": "NVDA", "sl": null, "tp": null, "alerts": [],
  "fibos": [{ "id": "f1", "t1": "2026-03-12", "p1": 142.3, "t2": "2026-07-08", "p2": 176.85 }],
  "marks": [{ "id": "m1", "t": "2026-03-12", "kind": "buy", "note": "ซื้อรอบแรก" }]
}
```
- `fibos`, `marks` ไม่บังคับ (หุ้นเดิมไม่มี = ว่าง)
- `kind` ∈ `buy | sell | news | other`
- ลำดับหุ้น = ลำดับใน `symbols`
- ตัวเช็ก (Python) อ่านและเขียนทั้งไฟล์โดยไม่ตัดคีย์ที่ไม่รู้จัก — ยืนยันด้วย test

## คำสั่งใหม่ของ `/api/change`

| action | ฟิลด์ | กติกา |
|---|---|---|
| `reorder` | `order: [symbol…]` | ต้องเป็นการสลับลำดับของรายการปัจจุบันพอดี |
| `add_fibo` | `t1, p1, t2, p2` | วันที่ `YYYY-MM-DD`, ราคา > 0, `t1 ≠ t2`, `p1 ≠ p2`, ≤ 3 ชุด |
| `remove_fibo` | `id` | |
| `add_mark` | `t, kind, note` | วันที่ถูกรูปแบบ, kind ถูกต้อง, note ≤ 200, ≤ 30 อัน |
| `update_mark` | `id, kind, note` | วันที่ไม่เปลี่ยน |
| `remove_mark` | `id` | |

## ข้อมูลราคา
- `/api/candles` ดึง `range=5y` แล้วเก็บ 956 แท่งล่าสุด (3 × 252 + 200 สำหรับ MA200)
- กราฟเปิดที่ 252 แท่งล่าสุดเหมือนเดิม
- เส้น 52w ยังคำนวณจาก 252 แท่งล่าสุด

## หน้าจอ
- แถบบนหน้ากราฟ: `‹ ชื่อหุ้น` ซ้าย, ปุ่มเล็ก `Fibo` `Mark` ขวา; บรรทัดที่สอง: ราคา, %, ป้ายแนวโน้ม
- RSI อยู่ในกราฟเดียวกัน ใช้ price scale แยกช่วงล่าง ~20% ของความสูง แกนวันที่อยู่ล่างสุด
- ระหว่างโหมด: กราฟหยุดเลื่อน/ซูม, ปุ่มของโหมดเป็น "ยกเลิก", ปุ่มอื่นกดไม่ได้, แตะค้างปิดชั่วคราว, แถบคำแนะนำใต้กราฟ
- รายการเส้นใต้ปุ่ม SL/TP/Alert มีแถว Fibo (`Fibo 142.30 → 176.85  12/3 – 8/7`) พร้อม "ลบ"
- หัวข้อรายการ note เป็นตัวเอียงแบบมีเชิง ข้อความเต็มในแถวที่กางใช้ตัวอักษรแบบมีเชิง

## นอกขอบเขต
- แจ้งเตือนจาก RSI หรือระดับ Fibo
- แก้จุดปลาย Fibo หลังบันทึก, ย้ายวันที่ของ mark
- ปุ่มเลือกช่วงเวลา, เปลี่ยนชื่อแอปบนหน้าจอหลัก
- ปีในวันที่ของรายการ note (`8/7` ไม่บอกปี ตามที่ผู้ใช้ขอให้สั้นที่สุด)
